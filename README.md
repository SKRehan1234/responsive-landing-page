# Nova - Responsive Landing Page

## Web Development Internship - Task 1

This project is a simple responsive landing page created according to the internship task requirements.

### Objective

Build a clean, responsive landing page with:

- Header with logo and navigation links
- Hero section with heading, paragraph, and call-to-action buttons
- Feature section
- About section
- Contact call-to-action
- Footer with social links

### Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Small JavaScript snippet for the mobile navigation menu

### Files

```text
responsive-landing-page/
├── index.html
├── style.css
└── README.md
```

### How to Run

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Resize the browser window to test the responsive design.

### Responsive Features

The page adapts to desktop, tablet, and mobile screen sizes using CSS media queries. The navigation changes into a mobile menu on smaller screens, and the grid layouts become single-column layouts.
